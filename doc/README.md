# Documentos

Esta pasta reúne os PDFs dos apêndices utilizados como materiais complementares do artigo sobre metodologia POE, Tinkercad e Robótica Educacional.

## Arquivos

- Apêndice A: Módulo 1 - Circuitos básicos envolvendo LED, resistores e botões.
- Apêndice B: Módulo 2 - Leitura e interpretação de sinais analógicos com Arduino.
- Apêndice C: Módulo 3 - Aplicações avançadas de controle digital com Arduino.
